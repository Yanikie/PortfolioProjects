Autonomous Mobile Platform

A platform that drives itself across hardpan land, so rainwater can be caught efficiently and used by the soil. Together with a team, I developed it in Gazebo for GreenDigger.

Partner
GreenDigger
Built with
Gazebo, C++, Python, OpenCV
Way of working
Team project, Scrum

Object recognition

Using OpenCV, the image from a depth camera is analysed to find obstacles. The result feeds the pathfinding algorithm.

  • OpenCV

    Edge detection

    First the image from the depth camera is read. It comes in grayscale, which makes it well suited for a Canny edge filter. Using the filtered image, bounding boxes are drawn around the now amplified edges.

  • Math

    Distance to the obstacle

    With the bounding boxes in place, the view of the camera tells where the next obstacle is. This calculation gives a vector to the object. Adding it to the position of the AMP at that moment results in the real coordinates of the obstacle.

Pathfinding

To drive autonomously, the platform needs a route. The previous step found the obstacles, now it has to navigate around them.

  • A*

    Choosing an algorithm

    GreenDigger supplied a map of the planned excavation spots. With it, the next goal can be determined, so a simple pathfinding algorithm with one start and one goal is enough. Since the position of the goal is known, we chose the heuristically informed A*: a fast algorithm that uses a heuristic function to plan the best route.

  • PID

    Driving the route

    With the route from A*, the platform drives from vertex to vertex: first it turns towards the next vertex, then it drives there. We chose this method because it leaves as little room for errors as possible, and the machine does not drive large distances.
