# Fiber

Fiber is my python game application. When trying to improve my python skills I decided it would be best to do this in a way I like. This for me was games.

All games and documentation are in dutch as this is my native language.

I also wanted to have an application which would see who would pay who. This is because this was the predecessor to a full out gambling system. I decided to keep it to a splitter. This can be found in the applications folder
