Porygon

A custom voice assistant, powered by an ESP32 Lolin D32 module and a dedicated server PC. Everything runs locally: no cloud, no monthly subscriptions. Ask a question and receive an answer.

Hardware
Lolin D32, INMP441, MAX98357
Software
Edge Impulse, Whisper, Ollama, Kokoro
Code on GitHub
Firmware, Server

Embedded system architecture

The physical pod: it listens for the wake word, records the question and plays the answer.

  • Brains

    Lolin D32

    For the brains I used the Lolin D32, simply because I still had this board lying around. If you want to build a similar project, I would recommend a similar ESP32 board or one with more RAM. The specs were enough for what I needed, but it's tight.

  • Audio

    Microphone and speaker

    For Porygon to hear what I am saying, it needed a microphone. The INMP441 is often used and was readily available. Most voice assistants can also talk back. For that I chose the MAX98357, which lets me use 4–8 ohm speakers that I still had lying around.

  • Wake word

    Edge Impulse

    There were a couple of options for wake word detection: ESP-SR, streaming the audio, transcribing locally or Edge Impulse. Edge Impulse took the most time to set up, but was also the best tuned for my application.

Server structure and model logic

Software on my own server PC that turns the recorded question into a spoken answer.

  • Speech to text

    Whisper

    The ESP32 streams the recorded audio to a TCP port on my server. The server needs to turn these bytes into text so the language model can respond. This is done with a speech to text model. Since OpenAI has made its Whisper model available for public use, I chose to use it.

  • Language model

    Llama 3.1 via Ollama

    I have a strong disdain for subscription-based services, so I was not going to call the API of one of the big names. Instead I call a model I host myself. I lose some recency, but gain a free model. I chose Llama 3.1 8B, since it runs fully in the VRAM of my GPU.

  • Text to speech

    Kokoro

    The text from the language model cannot be spoken yet. A text to speech model turns it into audio, which is sent to the ESP32 as bytes. I chose Kokoro TTS: it is fast and offers multiple voices, which makes the voice assistant sound more human.
